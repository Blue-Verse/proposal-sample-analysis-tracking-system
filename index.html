프로젝트 소개

핵심 요구사항 분석

  • 중앙 관제시스템 대시보드 — 전국 검사소별 데이터 취합 현황 실시간 그래프, 시료 분석 진행도 통계, 기간·지역·검사소별 조건 검색 및 필터링
  • 실시간 시료 추적 시스템 — 접수 → 분석중 → 분석완료 → 결과완료 상태 전환, 시료 고유 식별번호 자동 부여, 식별번호 검색을 통한 현재 처리 상태 실시간 조회
  • 분석 기록 연속성 확보 — 입력·수정·삭제 일시 및 작업자 계정 감사 로그, 중앙 관리자와 지역 검사소 요원 간 화면·데이터 접근 권한 분리(RBAC)
  • 인적 자원·장비 통합 관리 — 전국 분석 요원 정보 DB, 출퇴근·근무 이력, 필수 교육 이수 체크 및 증빙 파일 업로드, 검사소별 장비 정보(장비명·시리얼·점검일자) 관리
  • 알림 및 결과 연동 — 분석 완료 시 시스템 내 알림 발생, 결과 확인 대상자 대상 문자(SMS) 발송 API 연동, 문자 내 URL 클릭 시 외부인이 결과를 확인하는 단일 웹 페이지 제공

제안 포인트

본 프로젝트는 다수의 데이터를 취합하는 실시간 관제 대시보드와 상태 기반 워크플로우(시료 추적), 그리고 권한 분리·감사 로그가 핵심입니다. 이는 당사가 다수의 B2B 정보관리·관제 플랫폼에서 반복 수행해 온 영역과 정확히 일치합니다.

  • 실시간 취합·시각화 검증된 패턴 — 50+ 페이지 규모의 관리자 대시보드와 실시간 데이터 처리를 다수 수행한 경험을 바탕으로, 검사소별 취합 현황을 안정적인 차트 라이브러리(ECharts/Recharts)와 WebSocket 실시간 갱신으로 구현합니다.
  • 상태 워크플로우·식별번호 체계 — 다단계 결재·케어 로그 등 상태 전환 엔진을 설계한 경험으로, 시료 상태 전환과 고유 식별번호 자동 부여 로직을 무결성 있게 설계합니다.
  • 역할별 권한·감사 추적 — 6계층 보안과 7종 역할 권한(RBAC) 설계 경험으로 중앙 관리자와 지역 검사소 요원의 데이터 접근을 명확히 분리하고, 모든 입력·수정·삭제 행위를 감사 로그로 남깁니다.
  • 외부 셀프서비스 결과 페이지 — 토큰 기반 퍼블릭 페이지로 로그인 없이 외부 이해관계자가 정보를 확인하도록 구현한 경험이 있어, "문자 URL → 외부인 결과 확인 단일 페이지" 요구사항을 보안적으로 안전하게 충족합니다.
  • SMS 알림 연동 경험 — Ppurio 등 국내 문자 발송 API 연동 경험을 보유하여 분석 완료 알림·결과 통지를 안정적으로 처리합니다.

PRD (Product Requirements Document)

프로젝트 요구사항을 정의하고 기능 범위를 명확히 합니다.

1. 프로젝트 배경 및 목적

현재 검사소에서 산발적으로 도출되는 검사 결과를 NAS 서버에 개별 업로드하고 수기로 취합하여 타 기관에 전달하는 방식은 업무 비효율과 데이터 관리 부담을 초래하고 있습니다. 본 프로젝트는 분석의 신속성·정확성·체계성을 확보하는 정보관리시스템과, 전국 단위 분석 결과를 한눈에 확인하는 중앙 관제시스템을 통합한 웹 플랫폼을 구축하여 이 문제를 해결하는 것을 목적으로 합니다.

3. 기능 요구사항

3.1 중앙 관제시스템 대시보드

  • [필수] 전국 검사소별 데이터 취합 현황 실시간 그래프 표출
  • [필수] 검사소별 시료 분석 진행도 통계 수치 표출
  • [필수] 기간별·지역별·검사소별 조건 검색 및 데이터 필터링

3.2 실시간 시료 추적 시스템

  • [필수] 접수 → 분석중 → 분석완료 → 결과완료 상태값 변경 버튼 제공
  • [필수] 개별 시료에 대한 고유 식별 번호 자동 부여 로직
  • [필수] 식별 번호 검색을 통한 특정 시료의 현재 처리 상태 실시간 조회

3.3 분석 기록 연속성 확보

  • [필수] 데이터 입력·수정·삭제 일시 및 작업자 계정 정보 감사 로그 기록
  • [필수] 중앙 관리자와 지역 검사소 요원 간 화면·데이터 접근 권한 분리(RBAC)

3.4 인적 자원 및 장비 통합 관리

  • [필수] 전국 분석 요원 이름·소속 정보 데이터베이스
  • [필수] 분석 요원별 출퇴근 기록 입력 및 근무 이력 관리
  • [필수] 분석 요원별 필수 교육 이수 체크표 및 증빙 파일 업로드
  • [필수] 검사소별 장비명·시리얼 번호·점검 일자 입력·저장

3.5 알림 및 결과 연동 시스템

  • [필수] 시료 분석 완료 상태 변경 시 시스템 내 알림 발생
  • [필수] 결과 확인 대상자 연락처로 문자(SMS) 발송 API 연동
  • [필수] 문자 내 URL 클릭 시 외부인이 결과를 확인하는 단일 웹 페이지

호환성PC 기반 웹 표준 준수, 주요 브라우저(Chrome/Edge) 지원

5. 기술 제약사항

제안사 보유 최적 스택을 적용합니다. 프론트엔드는 Next.js(React)·TypeScript와 차트 라이브러리(ECharts/Recharts), 백엔드는 NestJS·TypeScript·PostgreSQL, 실시간 갱신은 WebSocket, 문자 발송은 국내 SMS API(Ppurio 등), 인프라는 클라우드(AWS) + Docker로 구성합니다. (최종 스택은 착수 시 클라이언트 환경·운영 정책에 맞춰 확정)

  • 모바일 전용 네이티브 앱 (본 과업은 PC 기반 웹 플랫폼)
